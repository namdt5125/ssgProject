## Đóng góp

Nếu bạn muốn đóng góp cho dự án này, vui lòng xem xét các bước sau:

1.  Fork dự án này.
2.  Tạo một nhánh mới (`git checkout -b feature/AmazingFeature`).
3.  Commit các thay đổi của bạn (`git commit -m 'Add some AmazingFeature'`).
4.  Push lên nhánh của bạn (`git push origin feature/AmazingFeature`).
5.  Mở một Pull Request.

Chúng tôi rất hoan nghênh các đóng góp của bạn!
